# Currency Rate Tracker

An application that retrieves currency exchange rate data and stores it in a MySQL database.

## Technologies

- Python
- MySQL
- SQL
- CSV
- JSON

## Features

Connects to a MySQL database using Python
Retrieves currency exchange rate data
Stores and works with structured currency data
Uses CSV and JSON files for data handling
Demonstrates database integration with a Python application

## How It Works

The application connects to a MySQL database and works with currency exchange rate data.
The project includes sample data stored in CSV and JSON formats, as well as a Python script responsible for interacting with the database.
The database structure and stored data can be viewed in the included MySQL screenshot.

## How to Run

1. Clone the repository
2. Install the Python package
pip install mysql-connector-python
3. Configure MySQL
Create a MySQL database and update the connection settings in msqlTest.py with your local MySQL credentials.
4. Run the application
python msqlTest.py
